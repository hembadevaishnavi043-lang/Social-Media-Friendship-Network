# Social-Media-Friendship-Network
1. Introduction

Social media platforms connect millions of users through friendship relationships. An adjacency matrix is used to represent these connections in the form of a matrix.

2. Problem Statement

To represent friendship connections between users using an adjacency matrix and identify whether two users are friends.

3. Objectives

To represent users using a graph.

To store friendship connections using an adjacency matrix.

4. Technology Used

Programming Language: Python

Data Structure: Adjacency Matrix

Platform: Visual Studio Code

5. Methodology

Each user is represented by a row and a column in the matrix. The value 1 indicates a friendship, while 0 indicates no direct friendship.

6. Algorithm

Create a list of users.

Initialize an adjacency matrix with zeros.

Add friendship connections to the matrix.

Display the adjacency matrix.

Check whether two users are friends.

Count the friends of each user.

7. Applications

Social networking websites

Friendship recommendation systems

Graph analysis

Network connection management
